# PPS DiSC Internal Prototype

## Scope

This app is an internal PPS/DiSC-style scoring prototype for instructor use.

Do not add:
- RBA features
- Insight card recommendations
- AI coach, chatbot, or external AI API calls

## Working Rules

- Keep questionnaire data, scoring logic, and interpretation text separated.
- Treat files under the parent `sources/` folder as read-only reference material.
- Current scoring is prototype scoring. Official conversion tables and final pattern rules must be verified against the instructor's authorized materials before production use.
- Prefer small, clear changes over broad rewrites.

## Useful Commands

- `npm install`
- `npm run dev`
- `npm run build`
